# 🍽️ Shivam Restaurant Website

A modern and responsive restaurant website built using pure HTML and CSS.

## 🌟 Features

* Responsive Design
* Beautiful Hero Section
* Food Gallery
* Popular Menu Items
* Customer Reviews
* Contact Information
* WhatsApp Order Button
* Clean and Modern UI
* Easy to Customize

## 🚀 Getting Started

1. Download the project files.
2. Open `Shivam_Restaurant_Website.html` in your browser.
3. Customize menu items, images, prices, and contact details as needed.
