# LUMIÈRE Fashion Website

LUMIÈRE is a modern fashion website built with React, TypeScript, and Vite. The project showcases timeless fashion collections, including womenswear, menswear, and accessories, with a clean and elegant user interface.

## Features

* Modern and responsive design
* Elegant typography using Playfair Display and Inter fonts
* Fast performance with Vite
* Built with React and TypeScript
* Mobile-friendly layout

## Technologies Used

* React
* TypeScript
* Vite
* HTML5
* CSS3

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/lumiere-fashion.git
```

2. Navigate to the project folder:

```bash
cd lumiere-fashion
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open your browser and visit:

```text
http://localhost:5173
```

## Build for Production

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```
